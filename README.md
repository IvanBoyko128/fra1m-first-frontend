# fra1m Courses

Одностраничное приложение для управления курсами, созданное с использованием React + TypeScript + Vite + Ant Design.

## Функционал

- 📚 Просмотр списка курсов
- 🔍 Поиск по названию курса
- ➕ Добавление новых курсов
- ✏️ Редактирование названия курса
- 🗑️ Удаление курсов
- ⭐ Добавление курсов в избранное
- 📖 Просмотр подробной информации о курсе

## Технологии

- **React 18** - библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый инструмент сборки
- **Ant Design** - библиотека UI компонентов
- **useReducer** - управление состоянием приложения

## Установка и запуск

### Локальная разработка

1. Клонируйте репозиторий:

```bash
git clone <repository-url>
cd fra1m-first-frontend
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите приложение в режиме разработки:

```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Docker

1. Соберите Docker образ:

```bash
docker-compose build
```

2. Запустите приложение:

```bash
docker-compose up -d
```

3. Откройте браузер и перейдите по адресу `http://localhost:3000`

## Использование

1. **Просмотр курсов**: На главной странице отображается список всех курсов
2. **Поиск**: Используйте поле поиска для фильтрации курсов по названию
3. **Добавление курса**: Нажмите кнопку "Добавить курс" и заполните форму
4. **Редактирование**: Нажмите на иконку редактирования в карточке курса
5. **Удаление**: Нажмите кнопку "Удалить" и подтвердите действие
6. **Избранное**: Нажмите на звездочку для добавления/удаления из избранного
7. **Подробности**: Нажмите "Подробнее" для просмотра описания и списка уроков

## Состояние приложения

Приложение использует `useReducer` для управления состоянием. Поддерживаются следующие действия:

- `ADD_COURSE` - добавление нового курса
- `UPDATE_COURSE_TITLE` - изменение названия курса
- `DELETE_COURSE` - удаление курса
- `TOGGLE_FAVORITE` - переключение статуса избранного
- `FILTER_COURSES` - фильтрация курсов по названию
